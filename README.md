# Operating Systems Lab

This repository contains the practical work for the Operating Systems laboratory.

## Structure

- Lab1 - System Calls and CPU Scheduling
- Lab2 - Threads, Synchronization and Deadlocks
- Lab3 - Memory, I/O and Disk Management
- Lab4 - File Systems and File Management
- Capstone - Operating Systems monitoring and analysis project

## Environment

- Ubuntu 24.04 LTS
- Python 3.12.3
- Git 2.43.0
- Bash 5.2
- Python virtual environment: .venv

## Python Libraries

- psutil
- pandas
- matplotlib

## Running Python Programs

Activate the virtual environment:

source .venv/bin/activate

Then run a Python program using:

python filename.py
